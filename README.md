# My Logic Challenges 💻

Repositorio personal de Israel Amaya donde documento mi proceso de aprendizaje y práctica en programación.

Este repositorio reúne ejercicios, retos, tareas y pequeños proyectos desarrollados mientras fortalezco mis habilidades de lógica, programación y desarrollo de software.

## 📚 Contenido

### 🐍 Python

Ejercicios enfocados en los fundamentos del lenguaje:

* Hello World
* Variables
* Operadores
* Fundamentos de programación
* Práctica de lógica

### 🟨 JavaScript

Ejercicios y actividades para practicar:

* Variables y operaciones
* Condicionales
* Ciclos
* Resolución de problemas
* Lógica de programación

### 🌐 HTML & CSS

Pequeños ejercicios y páginas utilizadas para practicar:

* Estructura HTML
* Estilos CSS
* Integración con JavaScript
* Ejercicios interactivos

El objetivo de este repositorio es practicar de manera constante y construir una base sólida en programación.

Los ejercicios aumentan progresivamente en dificultad y sirven como registro de mi evolución, desde los conceptos más básicos hasta problemas que requieren mayor razonamiento lógico.
